# 🌦️ Weather Forecast Application

A real-time weather forecasting web application that provides live weather updates and forecasts using weather API integration.

## 🚀 Live Demo

**Live Site:** https://weatherbyibnabubakri.netlify.app/

## ✨ Features

- 🌡️ Real-time weather updates
- 📍 Location-based forecasting
- 📊 Detailed weather metrics (temperature, humidity, wind speed)
- 🎨 Responsive design for all devices
- 🌙 Dark/Light mode support

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **API:** Weather API Integration
- **Deployment:** Netlify

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/IbnAbubakri/WeatherForecast.git

# Navigate to directory
cd WeatherForecast

# Install dependencies
npm install

# Create .env.local file
echo "NEXT_PUBLIC_WEATHER_API_KEY=your_api_key_here" > .env.local

# Run development server
npm run dev
```

## 🔧 Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_WEATHER_API_KEY=your_openweathermap_api_key
```
